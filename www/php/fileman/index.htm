File Manager

What Is It?

A file management tool for small to medium groups. A way for people to share or submit files.

Download

fileman.zip

Installation Instructions

  1. Use schema.sql to create your database
  2. Edit init.php to set your MySQL login details and some paths
  3. Edit head.txt and foot.txt to look snazzy
  4. Make sure the 'files' folder is writable by php
  5. Edit .htaccess to password protect admin*.php
  6. Profit!
